# 02 — 全機備份，建立唯一的回頭路

**What to build:** 對 VM 103 做一次 `vzdump` 全機備份，並**驗證它可讀**。

票 01 保全的是「知道自己需要的東西」。這一票保的是「還沒發現自己需要的東西」——
銷毀之後才想起來的那些。快照 `pre-demo-entrance-20260813` 會跟著 `qm destroy` 一起消失，
所以它不算回復點。

備份在**停機狀態**做：VM 先 `qm shutdown`，確認 `stopped` 之後再 `vzdump`。停機備份不必
處理一致性問題，而且此時已經沒有人在用這台機器。壓縮用 `zstd`，目標存放區 `local`
（dir 型，可用約 845 GiB）。

備份完成後不是看 `vzdump` 的結束碼就算數 —— 要**列出封存內容**確認讀得出來，並記錄
檔名、大小與 SHA-256。這份記錄跟票 01 的報告放在一起。

備份不刪。保留到新機器通過票 07 的驗收，且使用者明確說可以刪為止。
